# Règles à lire avant toute action

- **Toujours git.** Chaque livrable (images, scripts, docs) est commité.
- **Toujours `main`.** Checkout `main`, pull, travail, commit, `git push origin main`.
- Pas de branche parallèle (`cursor/...`), pas de pull request, sauf demande explicite.
- Relire ce fichier au début de chaque session.
