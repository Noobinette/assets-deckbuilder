# Boite — propositions de jaquette

Dix visuels de face de boîte, pixel art old-school fantasy, format portrait **1728×2304** (plus grand que les dos de cartes 750×1050).

Titre **PIXEL OF GLORY** intégré, cadre or, même univers que les illustrations des cartes (griffon, nains, orcs, dragon, compagnie, donjon).

Ouvrir `apercu.html` pour tout voir côte à côte. Planche : `planche.jpg`.
